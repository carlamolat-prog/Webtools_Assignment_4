# Webtools_Assignment_4
Building a Local Weather Page for Webtools Class
This uses the OpenWeather app for API. 

Files as follows:
index.html for layout
index.js for javascript and interactive elements
style.css for a minimalist layout to present weather data as a single card after the city is entered by the user.

Note: Per api.openweather.org, to get a valid result the city and two digit country shorthand must be entered to prevent city not found errors. (i.e. Type Orlando, US versus just Orlando to get weather for that location).

Icon loading is only issue so far.
